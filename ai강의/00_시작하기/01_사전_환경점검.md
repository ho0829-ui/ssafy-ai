# 사전 환경 점검

수업 전날까지 아래 항목을 확인합니다.

## 필수

- [ ] Windows 10 또는 Windows 11 PC를 사용합니다.
- [ ] Chrome 또는 Edge에서 일반 웹페이지를 열 수 있습니다.
- [ ] TypingMind 접속 경로와 계정을 확인했습니다.
- [ ] Visual Studio Code가 설치되어 실행됩니다.
- [ ] VS Code에 GitHub Copilot Chat을 사용할 수 있는 계정으로 로그인했습니다.
- [ ] Git for Windows가 설치되어 VS Code 터미널에서 Git Bash를 선택할 수 있습니다.
- [ ] Node.js가 설치되어 있습니다.
- [ ] 압축 파일을 영문 또는 한글 사용자 문서 아래의 짧은 경로에 풀었습니다.

권장 예시 경로:

```text
C:\ssafy\ai-course
```

## 계정·사용량 문제가 있을 때

TypingMind 또는 Copilot 사용량이 제한되면 다음 순서로 참여합니다.

1. 강사 시연 화면으로 Agent의 입력, 출력 관계를 확인합니다.
2. 제공된 Markdown 파일에서 지침과 Session 산출물을 직접 비교합니다.
3. 모델 실행이 필요한 단계의 결과는 강사용 공통 결과와 대조합니다.
