# 설치 및 실행 확인

## 1. VS Code에서 Git Bash 열기

1. VS Code를 실행합니다.
2. 상단 메뉴에서 `Terminal` → `New Terminal`을 선택합니다.
3. 터미널 오른쪽의 프로필 선택 메뉴에서 `Git Bash`를 선택합니다.
4. 아래 명령을 한 줄씩 실행합니다.

```bash
git --version
node --version
```

두 명령 모두 버전 문자열이 표시되면 준비된 상태입니다.

## 2. Starter 웹 앱 열기

1. VS Code에서 `File` → `Open Folder`를 선택합니다.
2. 각 폴더 안의 `ssafy-learning-planner` 폴더를 엽니다.
3. Explorer에서 `index.html`을 찾습니다.
4. `index.html`을 브라우저로 엽니다.

## 3. Copilot Chat 확인

- VS Code에서 Chat 보기를 열 수 있는지 확인합니다.
- 새 Chat을 만들 수 있는지 확인합니다.
- Agent 선택 영역이 보이는지 확인합니다.

화면 이름과 버튼 위치는 설치 시점에 따라 달라질 수 있습니다. 기능이 보이면 같은 것으로 판단합니다.

## 오류별 빠른 확인

| 증상 | 먼저 확인할 것 |
|---|---|
| `git: command not found` | Git for Windows 설치와 터미널 프로필 |
| `node: command not found` | Node.js 설치 후 VS Code 완전 종료·재실행 |
| 브라우저가 빈 화면 | `index.html`, `style.css`, `app.js`가 같은 폴더인지 확인 |
| Copilot Chat이 열리지 않음 | 확장 설치, 로그인, 교육 계정 권한 확인 |
| 한글 경로에서 명령 오류 | `C:\ssafy\ai-course`처럼 짧은 경로로 이동 |
