# SSAFY 학습 플래너 Agent 운영 계약

- docs/task.md와 docs/plan.md를 먼저 읽는다.
- 수정할 파일과 실행할 명령을 먼저 보고하고 승인을 기다린다.

## 수정 범위
- 기본 허용 파일은 validation.js, app.js, tests/validation.test.js다.
- index.html과 style.css는 오류 표시 UI에 필요한 최소 범위만 수정한다.
- 계획에 없는 파일, 외부 패키지, 서버, API를 추가하지 않는다.

## 중단 조건

- 명령의 목적 또는 대상이 불분명한 경우
