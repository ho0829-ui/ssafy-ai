# 상태별 필터 기능 추가

## 목표
사용자가 학습 목록을 전체, 진행 중, 완료 상태로 나누어 볼 수 있게 한다.

## 요구사항
1. 목록 위에 `전체`, `진행 중`, `완료` 버튼을 표시한다.
2. 버튼을 선택하면 해당 상태의 항목만 목록에 표시한다.
3. 선택된 버튼은 다른 버튼과 시각적으로 구분한다.
4. 항목을 추가하거나 완료 상태를 바꾸면 현재 필터 결과가 즉시 갱신된다.
5. 기존의 항목 추가, 완료 상태 변경, 삭제 기능은 계속 동작해야 한다.

## 제약
- HTML, CSS, JavaScript만 사용한다.
- 외부 라이브러리와 패키지를 추가하지 않는다.
- 현재 화면의 기본 구조와 색상 체계를 유지한다.
- 필터 기능과 직접 관련 없는 코드는 수정하지 않는다.

## 완료 결과
- 변경된 웹 앱
- 확인 절차와 결과
- docs/review.md의 최종 판정
