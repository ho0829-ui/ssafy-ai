# 학습 항목 입력 검증 분석

## 현재 확인한 사실
- app.js의 submit handler가 입력값을 받아 항목을 추가한다.
- 상태 필터, 완료 변경, 삭제 뒤 같은 렌더링 함수를 사용한다.
- validation.js와 validation.test.js는 핵심 규칙을 완성할 뼈대다.

## 영향 파일
- validation.js: DOM과 분리된 입력 검증 함수
- app.js: 검증 결과에 따른 추가 또는 오류 표시
- tests/validation.test.js: 공백과 40자 경계 검증
- index.html, style.css: 오류 표시 연결에 필요한 최소 범위

## 제외 범위
- 데이터 영구 저장
- 화면 전체 재설계
- 외부 검증 라이브러리

## 위험
- 브라우저와 테스트가 서로 다른 검증 규칙을 사용하면 결과가 어긋날 수 있다.
- 검증 추가 과정에서 기존 필터·완료·삭제 흐름이 깨질 수 있다.
