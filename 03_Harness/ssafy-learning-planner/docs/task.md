# 학습 항목 입력 검증

## 목표
잘못된 학습 항목은 추가하지 않고 실패 이유를 화면에 표시한다.

## 필수 요구사항
1. 입력값의 앞뒤 공백을 제거한 뒤 검증한다.
2. 빈 문자열과 공백만 있는 문자열은 추가하지 않는다.
3. 40자를 초과한 문자열은 추가하지 않는다.
4. 검증 실패 이유를 입력 영역 근처에 표시한다.
5. 정상 입력은 기존과 같이 추가한다.
6. 필터·완료·삭제 기능은 계속 동작해야 한다.

## 제약
- HTML·CSS·JavaScript만 사용한다.
- 외부 패키지·서버·API를 추가하지 않는다.
- 입력 검증과 관계없는 화면 재설계를 하지 않는다.
