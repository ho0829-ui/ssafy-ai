# TypingMind로 Agent 이해하기

## 목표

같은 학습 계획 요청을 일반 채팅과 저장된 Agent에 각각 입력하고, Agent가 저장된 목표, 절차, 출력 형식에 따라 행동하는지 비교합니다.

## 파일

- [`01_실습_순서.md`](01_실습_순서.md): 처음부터 끝까지 진행 순서
- [`02_복사용_프롬프트.md`](02_복사용_프롬프트.md): 일반 채팅과 Agent에 입력할 문장
- [`03_System_Instruction.md`](03_System_Instruction.md): Agent에 저장할 공통 지침
- [`04_결과_비교_기록지.md`](04_결과_비교_기록지.md): 결과 확인용 체크리스트

모델마다 문장과 세부 계획은 달라질 수 있습니다. 
확인할 것은 정답 문장 일치가 아니라 질문 순서, 시간 제한, 완료 조건, 출력 형식입니다.
