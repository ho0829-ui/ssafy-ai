# 복사용 프롬프트

## 기준 프롬프트

```text
이번 주에 HTML, CSS, JavaScript를 학습하려고 합니다.
5일 동안 수행할 학습 계획을 만들어 주세요.
```

## Agent의 질문 뒤에 입력할 추가 정보

```text
프로그래밍을 학습한 지 2주 되었습니다.
하루에 2시간 사용할 수 있습니다.
이번 주에는 할 일을 추가하고 완료 상태를 표시할 수 있는 간단한 웹페이지를 만들고 싶습니다.
```

## 개선 후 재실행

Agent 설정을 수정한 뒤에는 기존 대화가 아닌 새 Agent 대화에서 `기준 프롬프트`부터 다시 시작합니다.
