# 실습 순서

## A. 일반 채팅 기준 결과 만들기

1. 새로운 일반 채팅을 엽니다.
2. 현재 사용할 수 있는 모델을 선택합니다.
3. [`02_복사용_프롬프트.md`](02_복사용_프롬프트.md)의 `기준 프롬프트`만 입력합니다.
4. 응답을 받은 뒤 [`04_결과_비교_기록지.md`](04_결과_비교_기록지.md)의 일반 채팅 열을 표시합니다.

## B. 학습 플래너 Agent 만들기

1. TypingMind의 Agent 생성 화면을 엽니다.
2. 이름을 `SSAFY 학습 플래너`로 입력합니다.
3. 설명을 `학습자의 경험과 시간을 확인한 뒤 실행 가능한 5일 프로그래밍 학습 계획을 만드는 Agent`로 입력합니다.
4. [`03_System_Instruction.md`](03_System_Instruction.md)의 본문을 System Instruction 영역에 붙여 넣습니다.
5. 현재 사용 가능한 모델을 선택하고 나머지 고급 설정은 기본값으로 둡니다.
6. Agent를 저장합니다.

## C. 같은 요청으로 Agent 확인하기

1. 저장한 `SSAFY 학습 플래너`를 선택해 새 대화를 엽니다.
2. 일반 채팅과 같은 기준 프롬프트를 입력합니다.
3. Agent가 계획을 바로 작성하지 않고 세 가지 정보를 질문하는지 확인합니다.
4. [`02_복사용_프롬프트.md`](02_복사용_프롬프트.md)의 `추가 정보`를 입력합니다.
5. 결과 표를 확인하고 비교 기록지를 완성합니다.

## D. 한 번 개선하기

결과에서 실제로 발견한 문제 하나만 선택합니다. System Instruction의 관련 규칙 한 줄만 수정한 뒤 새 Agent 대화에서 다시 실행합니다.
